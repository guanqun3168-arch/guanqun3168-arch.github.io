# 冠群建築師事務所 網站

純靜態網站。不需要安裝任何東西，用瀏覽器直接打開 `index.html` 就能看。

## 檔案在哪

| 你想改什麼 | 打開哪個檔 |
| --- | --- |
| 首頁文字 | `index.html` |
| 首頁的精選作品 | `index.html`（獨立清單，見下方說明） |
| 作品列表 | `works/index.html` |
| 某個作品的內頁 | `works/類別-編號/index.html` |
| 事務所簡介 | `about.html` |
| 聯絡方式 | `contact.html` |
| 顏色、字體、間距 | `assets/css/style.css` |
| 圖片 | `assets/img/` |

## 怎麼新增一個案子

1. 在 `works/` 底下新增一個資料夾，名字沿用**事務所自有的案件編碼**。
   只要是半形英數與連字號都可以，例：`works/h88-temple/`。

   > 資料夾名稱不要用中文。中文會被瀏覽器編碼成 `%E9%87%91...` 這種亂碼網址，
   > 而且在 Mac 與 Windows 之間搬檔時容易出現「路徑存在卻找不到圖片」。
   > 網頁上顯示的案名用中文完全沒問題，那是另一回事。

2. 把 `works/example-project/index.html` 複製一份到新資料夾裡，檔名一樣叫 `index.html`。

3. 圖片用 `tools/photo-style.py` 處理，它會自動壓縮、縮圖並套上事務所的統一色調：

   ```
   python photo-style.py 原始照片.jpg h88-temple-02
   python photo-style.py 原始照片.jpg cover --cover
   ```

   處理好的檔案會自動存進 `assets/img/`。
   **不要用其他軟體調色**，色調會不一致。第一次使用要先裝套件：`pip install pillow numpy`

4. 打開新資料夾裡的 `index.html`，把這些地方換掉：
   - `<title>` 裡的案名
   - 頁面上的案名、地點、面積、年份、類型
   - 圖片的 `src` 路徑與 `alt` 文字（**每張圖都一定要有 alt**）
   - 案例說明文字

5. 回到 `works/index.html`，複製一個 `<li class="work-item">` 區塊，
   改成新案子的名稱、年份與連結。連結寫 `nanhai-house/`。

6. 存檔，用瀏覽器打開確認。

> 沒有確定的資訊就留「待補」，不要先隨便填一個數字。
> 業主名稱沒有經過對方同意，不要放上去。

## 首頁的「精選作品」

首頁那一排作品是**你自己挑的**，跟作品頁是兩份清單。
在作品頁新增案例時，首頁不會自動跟著變 —— 這是刻意的，
才能決定第一眼要讓訪客看到哪幾件。

要換精選作品，打開 `index.html`，找到「精選作品」那段註解，
底下每個 `<li>` 就是一件。複製一個改掉連結、圖片與標題即可，
不想推的整段刪掉。建議維持三到六件。

## 怎麼上線

見下方「上線到 GitHub Pages」。上線前請先確認：

- 所有頁面互相連得到，沒有死連結
- 手機（375px 寬）與桌機都看過一次
- 圖片都壓縮過，也都有 alt

## 上線到 GitHub Pages

1. 初始化 git，並確認 `.gitignore` 已存在
2. 建立 GitHub repository（公開）
3. 推送目前的檔案
4. 開啟 GitHub Pages，指定來源分支
5. 拿到網址後，用無痕視窗打開，逐頁點過一次

上線後大約幾分鐘內生效。如果改壞了，可以在 GitHub 的 commit 紀錄裡找到上一個可用版本還原。

**注意：不要把任何金鑰或私人資料放進 repository。**
